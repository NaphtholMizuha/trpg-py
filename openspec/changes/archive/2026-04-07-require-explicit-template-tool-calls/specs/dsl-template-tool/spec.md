## 新增需求

### 需求:template 必须作为真实 agent 工具调用暴露
系统必须将 `template` 作为 `dsl_node` agent 可直接调用的真实工具暴露，禁止仅由宿主代码在 agent 运行前预取模板结果并伪装成工具能力。

#### 场景:dsl_node 查询模板
- **当** `dsl_node` 需要某类任务族的合法 DSL 骨架
- **那么** agent 必须能够直接调用 `template`
- **那么** 模板查询不得要求宿主在 agent 调用前先完成同等查询

### 需求:template 工具调用必须可观察
系统必须为 `template` 提供与 `lint` 类似的可观察性，禁止真实运行时完全看不出 `template` 是否被调用。

#### 场景:template 工具完成一次查询
- **当** agent 调用了 `template`
- **那么** 系统必须记录该次查询的受控枚举字段或等价诊断信息
- **那么** 系统必须记录本次查询是否命中模板
- **那么** 系统必须在命中时记录 `template_id`
- **那么** 系统必须在发生回退时记录回退状态
