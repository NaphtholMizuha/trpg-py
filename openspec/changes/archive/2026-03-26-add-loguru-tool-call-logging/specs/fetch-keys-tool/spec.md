## 新增需求

### 需求:fetch_keys 工具每次调用必须使用 loguru 记录输入和输出
系统必须要求 `fetch_keys` 工具在每次调用时通过 `loguru` 记录调用输入、输出状态和错误信息，禁止把这类日志责任留给上层调用方临时实现。

#### 场景:fetch_keys 返回命中路径
- **当** 调用方向 `fetch_keys` 提交有效参数且工具返回 `status=ok`
- **那么** 系统必须记录本次调用的输入参数摘要
- **那么** 系统必须记录返回状态为成功以及路径数量等结果摘要

#### 场景:fetch_keys 无命中
- **当** 调用方向 `fetch_keys` 提交有效参数且工具返回 `status=no_match`
- **那么** 系统必须记录本次调用的输入参数摘要
- **那么** 系统必须记录无命中状态

#### 场景:fetch_keys 调用失败
- **当** `fetch_keys` 在执行过程中发生异常并返回错误语义
- **那么** 系统必须记录本次调用的输入参数摘要
- **那么** 系统必须记录错误类型和错误信息
