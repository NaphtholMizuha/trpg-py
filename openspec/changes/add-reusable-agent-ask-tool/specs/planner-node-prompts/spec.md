## 新增需求

### 需求:主 agent 与 Context Agent 的默认指引必须教会其何时使用 ask
系统必须为主 agent、Context Agent 或其等价默认指引提供明确约束，教会它们在背景未明晰但已能组织出明确确认问题时调用 `ask`。系统禁止继续让 agent 在这类场景里只输出松散问题文本，或在没有默认建议与自定义输入入口的情况下发起 ask。

#### 场景:Context Agent 处理可枚举歧义
- **当** Context Agent 发现目标、位置或规则解释存在有限候选
- **那么** 默认指引必须要求它优先调用 `ask`
- **那么** ask 内容必须给出候选选项
- **那么** ask 内容必须给出推荐或默认选项
- **那么** ask 内容必须保留自定义输入入口

#### 场景:agent 处理无法明确收敛的缺口
- **当** agent 还无法把缺口收敛成明确问题或有限候选
- **那么** 默认指引不得强迫其调用 ask
- **那么** agent 可以继续返回内部备注、错误信息或等价的非交互性说明
