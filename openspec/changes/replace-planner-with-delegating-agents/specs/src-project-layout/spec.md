## 修改需求

### 需求: 手动 smoke 与自动 tests 必须在 src 下保持分层
系统必须将自动测试组织在 `src/tests/`，并允许版本化评测夹具继续位于 `examples/evals/` 或等价目录。系统禁止继续把 `src/smoke/` 作为长期目录真相，也禁止要求维护者通过手动 smoke 目录来表达正式验证契约。

#### 场景:维护者新增验证入口
- **当** 维护者新增一个自动测试文件或评测夹具
- **那么** 自动测试创建在 `src/tests/`
- **那么** 评测数据创建在 `examples/evals/` 或等价版本化夹具目录
- **那么** 维护者不得再以 `src/smoke/` 作为长期验证入口目录
