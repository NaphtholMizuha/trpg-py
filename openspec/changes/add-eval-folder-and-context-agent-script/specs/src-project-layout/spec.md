## 修改需求

### 需求: 手动评测与自动 tests 必须在 src 下保持分层
系统必须将正式运行时代码组织在 `src/augury/`，将自动测试组织在 `src/tests/`，并允许将长期保留的结构化评测脚本组织在 `src/eval/`。系统禁止把人工评测脚本重新放回 `src/smoke/`，也禁止把 `src/eval/` 退化成随意堆放临时脚本的目录。

#### 场景:维护者新增验证入口
- **当** 维护者新增一个自动测试文件或人工运行的结构化评测脚本
- **那么** 自动测试创建在 `src/tests/`
- **那么** 长期保留的人工评测脚本创建在 `src/eval/`
- **那么** 维护者不需要再通过 `src/smoke/` 表达正式验证入口
