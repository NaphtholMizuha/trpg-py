## 新增需求

### 需求:agent runtime 必须支持可中断工具的统一运行时语义
系统必须允许 agent runtime 中的工具在执行过程中触发 interrupt，并在宿主提供恢复输入后继续执行。系统禁止要求业务方为了支持人类交互而显式拆分成固定的人类节点图。

#### 场景:工具触发 interrupt
- **当** 某个工具调用需要等待宿主或人类提供输入
- **那么** runtime 必须能够把该工具调用标记为 pending interrupt
- **那么** runtime 必须保留足够的上下文以便后续恢复执行

#### 场景:工具在恢复后返回结果
- **当** 宿主为 pending interrupt 提供恢复输入
- **那么** runtime 必须恢复该工具调用
- **那么** 工具必须能够向 agent 返回最终结果并允许 agent 继续执行

### 需求:Python CLI 可以为可中断工具提供同步外观
系统必须允许 Python CLI 宿主把 interrupt/resume 过程表现成同步问答体验。系统禁止因为 CLI 提供同步外观而改变底层可中断工具的长期运行时语义。

#### 场景:CLI 同步展示 ask
- **当** Python CLI 宿主运行到可中断工具并需要人类输入
- **那么** 宿主可以在当前终端中同步收集回答
- **那么** runtime 必须在同一次 CLI 运行里恢复并继续 agent 执行
