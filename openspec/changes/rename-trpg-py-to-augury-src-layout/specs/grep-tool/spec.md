## 修改需求

### 需求:grep 工具必须驻留在 agent.tools 命名空间
系统必须在 `augury.agent.tools` 命名空间下提供名为 `grep` 的状态路径检索工具能力，并且该能力必须可以被 Python 调用方直接导入和使用，而不是仅作为 planner 内部私有辅助逻辑存在。

#### 场景:调用方从 agent.tools 使用 grep
- **当** 开发者为 planner 或其他 agent 组装工具集
- **那么** 可以从 `augury.agent.tools` 访问 `grep` 工具实现
- **那么** 调用方无需自行遍历全部 state 路径来做模糊筛选

### 需求:grep 工具必须提供可手动运行的 smoke 脚本
系统必须提供一个位于 `src/smoke/test_grep.py` 的可手动运行脚本，用于让开发者直接观察 `grep` 的路径检索、无命中和错误边界，而不是只能通过单元测试断言理解其行为。

#### 场景:开发者运行 grep smoke 脚本
- **当** 开发者在本地执行 `src/smoke/test_grep.py` 或等价命令
- **那么** 脚本会展示至少一次关键词命中结果
- **那么** 脚本会展示至少一次无命中结果
- **那么** 开发者可以从输出中看出 `grep` 的输入输出边界
