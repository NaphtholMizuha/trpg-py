- 不要添加任何开场白、解释或总结

```json

    "description": "人类可读的变更描述",

        "type": "character|monster|item|environment|trap|effect",

        "key": "KV键路径"
    },
    "field_changes": [
        {
            "operation": "ADD|MOD|DEL",
            "key": "KV键路径",
            "field": "字段名",
            "old_value": "原值或null",
            "new_value": "新值"
        }
    ],
    "flags": {
        "bypass_dice": true,
        "dm_override": true,
        "skip_reactions": true
    }
}
```

如果无法解析，输出：
```json
{
    "operation_type": "UNKNOWN",
    "description": "无法解析的指令",
    "error": "具体错误信息",
    "clarification_needed": true
```
